# 📱 Projeto iPhone em Java

Projeto desenvolvido em **Java** com o objetivo de representar algumas funcionalidades de um iPhone utilizando **Programação Orientada a Objetos (POO)** e **interfaces**.

## 🚀 Funcionalidades

O projeto simula três funcionalidades básicas de um navegador de internet:

- 🌐 Exibir página
- ➕ Adicionar página
- 🔄 Atualizar página
